Pure planner

Connect a project

This board keeps a plan in one JSON file in a GitHub repository, and edits it in place. Nothing about any project is built in — point it at yours.

  1. Mint a fine-grained token for that repository only, with Contents: read and write. Nothing else.
  2. Name the repository, the branch, and the path you want the file kept at.
  3. If the file is not there, it offers to create it.

The token stays in this browser and is never written into the file. Somebody else opening this page finds empty fields.
